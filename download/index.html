Download the miner, node & wallet

Standalone builds for the DriveCoin prototype privacy chain — single executables, no installation. The miner talks HTTPS straight to scan.drivecoinproject.online; the node joins the public network over P2P; the wallet manages your money.

🔐 Wallet keys are generated and stored on your machine only — keep the wallets.json / miner_wallet.json file safe.
Manage your money — Wallet

Create wallets, scan your balance with the view key, send confidential transactions and run Lightning channels. Works with a local node or the public chain — the same wallets.json format as wallet_app.py.

Run your own node — P2P

A self-contained DriveCoin node with full P2P: point it at --peer https://scan.drivecoinproject.online and a fresh node joins the public network, syncs the whole chain in seconds and stays in sync — blocks you mine are broadcast to every peer and appear on the explorer immediately. Or run an isolated private network with friends over LAN.

Quick start — your own node on the public network (2 minutes)

# 1. start a node joined to the public network (CLI…)
drivecoin-node-cli-windows-x64.exe --peer https://scan.drivecoinproject.online

# 2. …or GUI: open drivecoin-node-ui, press Start Node, add the peer in the P2P tab

# 3. mine on YOUR node — the block broadcasts to every peer automatically
drivecoin-miner-cli-windows-x64.exe --node http://127.0.0.1:8000 --once

# 4. manage your money with the standalone wallet
drivecoin-wallet-cli-windows-x64.exe new alice
drivecoin-wallet-cli-windows-x64.exe send alice <recipient> 10

Sync model, reorg rules, API & security notes → README-NODE.md in the node source zip. Wallet commands → README-WALLET.md in the wallet source zip.
